Estar On Indica

O programa de indicação oficial da Estar On Internet. Indique amigos, acompanhe cada etapa e seja recompensado.

🔒 Aplicativo Proprietário & Seguro
O que é

Um aplicativo de indicação completo

O Estar On Indica é uma plataforma web (PWA) desenvolvida exclusivamente para a Estar On Internet, que permite que clientes indiquem amigos e acompanhem todo o processo até a instalação.

Diferencial

Não é um sistema genérico. É um aplicativo proprietário, com identidade visual oficial, banco de dados próprio e segurança de nível empresarial.

Funcionalidades

Tudo em um só lugar

Para o Indicador

  • Cadastro em 3 etapas (dados, endereço, acesso)
  • Painel com KPIs em tempo real
  • Cadastro de indicações com ViaCEP
  • Chave PIX criptografada para recebimento
  • Acompanhamento de recompensas

Para o Gestor

  • Dashboard com gráficos e ranking
  • Gestão de indicações e status
  • Gestão de indicadores e chaves PIX
  • Controle de recompensas e campanhas
  • Relatórios e auditoria
Tecnologia

Banco de dados robusto e seguro

PostgreSQL via Supabase, com Row Level Security (RLS) em todas as tabelas. CPF sempre criptografado (AES-256 via Vault). Nenhum dado sensível é exposto.

Estrutura

  • profiles, referrals, rewards
  • payout_accounts (PIX criptografado)
  • referral_history (auditoria de status)
  • audit_logs (rastreabilidade)
  • settings (configuração da campanha)

Segurança no banco

  • RLS ativo em todas as tabelas
  • CPF cifrado com chave no Vault
  • Funções RPC com security definer
  • Permissões por papel (RBAC)
Segurança

Proteção de nível empresarial

Autenticação & Autorização

  • Supabase Auth (e-mail/senha)
  • Rotas protegidas por middleware
  • RBAC: admin, comercial, indicador
  • Sessões com expiração

Proteção de dados (LGPD)

  • CPF mascarado nas telas
  • Consentimento registrado
  • Termos e privacidade versionados
  • Auditoria de operações
🔒 LGPD Compliant & Auditado
Automação

Fluxo completo e automatizado

Recompensas são geradas automaticamente quando uma indicação é marcada como instalada. O gestor acompanha tudo em tempo real.

Status da indicação

Indicação recebida → Em análise → Atendemos a região → Contrato aprovado → Instalação agendada → Instalado → Recompensa gerada → Pagamento via PIX
